# AGENTS.md

## Domain language

Read [CONTEXT.md](CONTEXT.md) before naming anything — writing specs, docs, issues, tickets, commit messages, or code — or when the codebase uses a term you are about to paraphrase. It is the single source of truth for the domain vocabulary: each term's definition and the words to avoid (_User_ → Identity, _Organization_ → Tenant, …). Use its terms verbatim; when it names a concept, say what it says.
